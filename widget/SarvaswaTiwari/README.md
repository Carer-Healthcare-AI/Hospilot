# Hospilot Widget — Part 1

See `../../README_SarvaswaTiwari.md` for full assessment documentation.

## Local run

```bash
node server.js
```

Open `http://localhost:3000`.

## Environment variables

Copy `.env.example` to `.env` and set:

- `HOSPILOT_USERNAME`
- `HOSPILOT_PASSWORD`
- `HOSPILOT_BASE_URL`
- `CANDIDATE_NAME`

## Vercel deploy

Deploy this folder as a Vercel project with the same environment variables.
